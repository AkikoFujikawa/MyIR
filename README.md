# MyIR

### 人を支える経験から、新しい価値をつくる。

プログラミング学習初期に、HTML・CSS・JavaScriptの基礎を学びながら制作した  
自己紹介・キャリアポートフォリオです。

これまでの経験と、現在学んでいるWeb開発をつなぎながら、  
自分自身を「過去・現在・未来」の3つの視点からまとめました。

## 公開ページ

 [MyIRを見る](https://akikofujikawa.github.io/MyIR/)

## About

これまで、海外勤務、農業経営、旅行業、行政、子育て支援など、  
さまざまな分野で仕事を経験してきました。

環境や役割が変わるたびに学び直しながら、

- 人の話を聞く力
- 状況を整理する力
- 人と人をつなぐ調整力
- 新しいことを学び続ける力

を身につけてきました。

現在は、これまでの経験にIT・Web開発の学びを組み合わせ、  
人の困りごとを整理し、より使いやすい仕組みやサービスにつなげることを目指しています。
